# iOSMiniProjects

A collection of small iOS applications built with **Swift** and **UIKit**.  

## 📌 Projects Included

### 1. UITableView Demo (`tableview-demo` branch)
- Demonstrates the use of `UITableView` in a simple iOS app
- Implements data source and delegate methods
- Everything is contained in `ViewController.swift` for simplicity

### 2. Tip Calculator (`tip-calculator` branch)
- Calculates tip based on bill amount
- Interactive slider to select tip percentage
- Displays total amount including tip
- User-friendly interface with input validation

## 📂 Branch Structure
- `main` – Default branch (can contain README and project overview)
- `tableview-demo` – Contains the UITableView demo app
- `tip-calculator` – Contains the Tip Calculator app
